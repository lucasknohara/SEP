# SEP — StudyLens

## Sobre o projeto

O StudyLens é uma proposta de experiência inteligente para câmeras, a solução foi criada com o objetivo de transformar capturas de conteúdos de estudo em materiais mais organizados e úteis para aprendizagem.

O projeto possui dois principais modos de experiência:

* *StudyLens*: transforma capturas em conteúdos organizados para estudo, com recursos como melhoria de imagem, extração de texto, resumos e FlashCards.

* *Modo Customizável*: permite que o usuário crie seu próprio modo de câmera, escolhendo quais recursos deseja utilizar.

O projeto foi desenvolvido a partir do protótipo criado nas sprints anteriores e posteriormente migrado para React.

* JavaScript

## Funcionalidades

### Home

* Apresentação do projeto
* Apresentação dos modos StudyLens e Customizável
* Seção de funcionamento
* Funcionalidades do produto
* Estatísticas demonstrativas utilizando Math

### StudyLens

* Apresentação do modo estudante
* Visualização do protótipo
* Fluxo de captura até organização do conteúdo
* Ações de IA propostas para as capturas:

  * Transformação em PDF
  * Resumo de conteúdo
  * Extração de texto
  * Melhoria de imagem
  * Geração de FlashCards

### Modo Customizável

* Criação de um modo personalizado
* Definição do nome do modo
* Ativação de funcionalidades
* Prévia das funções selecionadas em tempo real
* Persistência das configurações utilizando localStorage

## Como instalar

É necessário ter o Node.js instalado na máquina.

Clone o repositório:

git clone https://github.com/lucasknohara/SEP

Entre na pasta do projeto:

cd SEP

Instale as dependências:

npm install

## Como executar

Depois de instalar as dependências, execute:

npm run dev

O Vite irá disponibilizar a aplicação em um endereço semelhante a:

http://localhost:5173

Abra o endereço informado no navegador.

## Usuários e senhas

A aplicação não possui sistema de autenticação.

## Uso de inteligência artificial

Durante o desenvolvimento, ferramentas de inteligência artificial foram utilizadas como apoio à equipe para orientação de implementação e esclarecimento de conceitos

Como por exemplo:

"Me ensine como um professor passo a passo de como usar o Math em JS"
"Me ensine como um professor passo a passo de como usar Props"

A definição do projeto, adaptação do protótipo, organização dos componentes, implementação das funcionalidades e validação do funcionamento da aplicação foram realizadas e revisadas pela equipe.
